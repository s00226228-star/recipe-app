レシピ帳 PWA 公開用ファイル

GitHub Pages等のWebホスティングに、このフォルダ内の5ファイルを同じ階層で置いてください。
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

公開後、AndroidのChromeでURLを開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

重要：登録レシピはブラウザ/インストールしたWebアプリのlocalStorageに保存されます。公開先にはアップロードされません。バックアップ機能で定期的にJSONを書き出し、Google Drive等にも保管してください。
